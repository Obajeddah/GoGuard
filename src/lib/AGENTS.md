## Transport and attendance rules

- Transport module: `organizations.transport_enabled` plus an active transport entitlement (trial or `transport_paid_until`; SQL `org_transport_active`, TS `billingState().transportActive`) unlocks `/fleet` (admin) and `/bus-app` (crew; admins may open it); bus write triggers enforce the entitlement. Ride/manifest rules live in `src/lib/bus.ts` and the offline queue in `src/lib/bus-offline.ts` (both tested). Bus-app writes carry client-generated ids (trip id, `client_id`) and are upserted with ignore-duplicates so offline re-sends are safe; integrity (pupil on this bus, guardian belongs to pupil, org) is enforced by triggers. Location points update `bus_trips.current_*` via trigger. Live views poll instead of using backend-specific realtime, to stay portable.
- `transport_notices` is the bus email outbox, filled only by triggers: `crew_change` (crew edits) and `pupil_boarded`/`pupil_dropped_off` (one per pupil bus log, never on ride start, with `member_id`/`guardian_id`). A future sender delivers them using `busRideRecipients` and `rideEmail` (`src/lib/ride-email.ts`, tested: the support links every ride email carries) and sets `emailed_at`.
- Bus pupils: parents tick `members.uses_bus` on the registration link (only when transport is on); setting `bus_id` forces `uses_bus` and checks the bus is the same school (trigger). Each member has a 64-char `bus_track_token` (immutable) for the public `/bus/$token` page served by `getBusTracking`; it shows a last-seen area name only (no map/coordinates) per `parentSeesLocation`; area names come from OpenStreetMap reverse geocoding cached in `place_names` (~100 m squares) so the service is hit rarely. Mass drop-off rule is `canDropAllAtSchool` in `src/lib/bus.ts`.
- Attendance is derived, never marked by hand: the `attendance_marks(_from,_to)` SQL function returns per-student gate/bus dates (Africa/Lagos), and `src/lib/attendance.ts` (tested) turns them into weekday present/absent marks per class; the Excel workbook (summary + one sheet per class) is built in the browser by `src/lib/attendance-excel.ts`.
